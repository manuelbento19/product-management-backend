# Product Management Backend

 A REST API for product management built with Node.js and TypeScript.

 This project was created while I was practicing backend development and exploring different software architecture and design patterns.

 ## About

 The project focuses on building a simple backend application while practicing:

 - REST API development
- TypeScript
- Express
- Authentication with JWT
- Password hashing with bcrypt
- Unit testing with Jest
- Clean Architecture
- Repository Pattern
- SOLID principles
- Singleton Pattern

 The project is intentionally simple and is mainly kept as part of my learning and development history.

 ## Technologies

 - Node.js
- TypeScript
- Express
- JSON Web Token
- bcrypt
- Jest

 ## Getting Started

 Clone the repository:

```
git clone https://github.com/manuelbento19/product-management-backend.git
```

 Go to the project directory:

```
cd product-management-backend
```

 Install the dependencies:

```
yarn
```

 ## Development

 Run the development server:

```
yarn dev
```

 ## Build

 Compile the TypeScript project:

```
yarn build
```

 ## Production

 After building the project, start the compiled application with:

```
yarn start
```

 ## Tests

 Run the test suite with:

```
yarn test
```

 ## Project Structure

